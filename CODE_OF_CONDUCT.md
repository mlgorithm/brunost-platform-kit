# Code of Conduct

We want Brunost to be a welcoming, technically rigorous open-source project.
Participants are expected to be respectful, assume good faith, give actionable
feedback, and keep discussions focused on the work.

Harassment, discrimination, threats, personal attacks, and publishing private
information are not acceptable. Project maintainers may remove comments,
close contributions, or restrict participation when this standard is not met.

Report concerns privately to the maintainers listed in the repository profile.
